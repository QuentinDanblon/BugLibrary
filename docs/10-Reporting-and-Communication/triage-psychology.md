# Triage Psychology

## What triage optimizes for

- Correctness  
- Repro time  
- Policy fit  
- Duplicate detection  
- Tone (adversarial hunters get slower benefit of doubt)  

## How to earn trust

| Do | Don’t |
|----|-------|
| Short clear replies | Essay rants on N/A |
| Extra PoC when asked | Move goalposts |
| Accept partial credit gracefully | Public shaming |
| Signal if PII minimized | Dump full DB “for proof” |

## Mediation

If wrong N/A: polite clarification with **new evidence**, reference policy lines, request re-review. Escalate via platform features, not social media.

## FR

Réduire le temps de repro. Ton pro. Contester avec preuves, pas avec ego.
