# Duplicates & N/A Handling

## Duplicate

- Ask what to improve next time (same root cause?)  
- Search your drafts before submit  
- Slightly different endpoints may still be same root — disclose related endpoints  

## Informative / N/A

| Reason | Response |
|--------|----------|
| OOS | Update personal scope notes |
| Best practice | Save for blog; don’t re-argue forever |
| Insufficient impact | Attempt chain or drop |
| Cannot repro | Offer meeting windows / more logs |
| Intended behavior | Re-check threat model; maybe still report differently |

## Emotional process

Log learning → next hypothesis. Never revenge-test out of scope.

## FR

Dup : apprendre la cause racine. N/A : classer la raison, améliorer le process. Pas de revenge-hack.
