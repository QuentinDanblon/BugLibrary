# Pre-Hunt Checklist

- [ ] Program policy read (today’s version)
- [ ] In-scope list extracted to notes
- [ ] Out-of-scope list extracted
- [ ] Rate / automation rules noted
- [ ] Safe harbor conditions understood
- [ ] Research accounts created & labeled
- [ ] Password manager entries unique
- [ ] Proxy scope filters set
- [ ] Collaborator / OOB ready if needed
- [ ] Hypothesis slot selected (not random browsing)
- [ ] Emotional state OK (not tilted)
- [ ] Time-box defined for session

## FR

Policy du jour, scope/OOS, rate, comptes labellisés, proxy filtrée, hypothèse choisie, time-box.
