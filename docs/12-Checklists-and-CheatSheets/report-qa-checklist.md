# Report QA Checklist

- [ ] Title specific (type + object + impact hint)
- [ ] Summary answers who/what/whom in 5 lines
- [ ] Steps work in clean profile
- [ ] Dual accounts labeled for authZ
- [ ] Expected vs actual stated
- [ ] Evidence redacted (no live tokens)
- [ ] Impact in business language
- [ ] Remediation actionable
- [ ] Asset clearly in scope
- [ ] Not a known duplicate of your own
- [ ] Severity not inflated
- [ ] Attachments openable and minimal

## FR

Repro propre, impact business, pas de tokens, pas d’inflation, scope vérifié.
