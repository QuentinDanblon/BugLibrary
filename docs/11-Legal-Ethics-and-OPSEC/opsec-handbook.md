# Hunter OPSEC Handbook

## Identity

| Layer | Practice |
|-------|----------|
| Research browser | Separate profile; no personal logins |
| Email | Dedicated aliases per program |
| Payments | Platform payout methods; tax hygiene |
| Devices | Disk encryption; lock screens |
| Network | Know your IP reputation; avoid shady botnets |

## Operational

- Password manager unique creds  
- 2FA on platform accounts  
- Encrypt notes at rest  
- Careful screenshots (no other notifs visible)  
- VPN policy: allowed by you; still not a license to OOS  

## Social OPSEC

- Don’t livestream live targets  
- Delay writeups per program disclosure  
- Watch for bait programs / scams  

## FR

Identité de recherche séparée, notes chiffrées, 2FA, pas de live de cibles, respect des délais de divulgation.
