# Skill Ladder / Échelle de compétences

## English — Advanced → Expert

| Level | Signals you are here | Primary investment |
|-------|----------------------|--------------------|
| **Advanced** | Valid mediums, some highs; still noisy recon; reports need rewrites | Methodology + access control + clean reports |
| **Advanced+** | Consistent highs; chains 2–3 issues; owns a niche (e.g. GraphQL) | Depth niche + automation that *filters* |
| **Expert** | Criticals via logic/design; low false-positive rate; mentors others | Novel hypotheses, program psychology, research ops |
| **Elite (top %)** | Repeatable edge on hard targets; public research; shapes industry practice | Original methodology, tooling quality, teaching |

### Force multipliers (in order)

1. **Reading code & design** faster than scanning  
2. **Business logic fluency** (money, identity, multi-tenant)  
3. **Communication** (triage trust compounds)  
4. **Selective automation** (signal, not volume)  
5. **AI agents** as junior teammates with hard guards  

### Weekly practice loop

```text
Mon: deep read of one in-scope feature (no tools)
Tue: hypothesis backlog (20+) — rank by EV
Wed–Thu: validate top 3 carefully
Fri: one excellent report or write-up for yourself
Sun: Living Document note — what changed in the craft?
```

### Metrics that matter (and ones that don’t)

| Track | Ignore |
|-------|--------|
| Valid report rate | Raw request count |
| Time-to-clear-triage | Social media flex |
| $ / focused hour | Leaderboard FOMO mid-hunt |
| Lessons written | Tool collection size |
