# Glossary / Glossaire

| Term | EN | FR |
|------|----|----|
| **ASM** | Attack Surface Mapping — inventory of reachable assets & trust boundaries | Cartographie de surface d’attaque |
| **BB** | Bug bounty | Bug bounty |
| **BOLA** | Broken Object Level Authorization (OWASP API1) | Autorisation objet défaillante |
| **BFLA** | Broken Function Level Authorization | Autorisation fonction défaillante |
| **EV** | Expected value — P(find) × impact × ease / cost | Espérance de valeur d’une piste |
| **Hypothesis-driven hunting** | Test explicit claims about system behavior | Hunting par hypothèses |
| **IDOR** | Insecure Direct Object Reference | Référence directe non sécurisée |
| **OPSEC** | Operational security for the hunter | Sécurité opérationnelle du hunter |
| **RoE** | Rules of Engagement | Règles d’engagement |
| **Scope** | Explicitly allowed targets & actions | Périmètre autorisé |
| **SSRF** | Server-Side Request Forgery | Requête serveur forgée |
| **VDP** | Vulnerability Disclosure Program | Programme de divulgation |
| **Living Document** | Continuously maintained reference | Document vivant |
| **Signal** | True positive likelihood of recon/automation output | Qualité du signal |
| **Triage** | Program review of your report | Triage / validation programme |
| **Chain** | Combining multiple weaker issues into stronger impact | Chaînage |
| **Tenant isolation** | Multi-customer data/control separation | Isolation multi-locataire |
| **Safe PoC** | Minimal proof without destructive side effects | Preuve de concept non destructive |

### Severity language

Use program-specific severity when provided. Otherwise CVSS as **communication aid**, not absolute truth. Business impact (PII, money, admin) often outweighs pure technical scores.
