# Continuous Learning Path

## Weekly

- 1 deep feature read (no tools)  
- 1 write-up (public or private)  
- 1 skill drill (e.g. OAuth lab)  

## Monthly

- Review graveyard hypotheses — patterns?  
- Update personal checklists  
- Read program changelogs of main targets  

## Yearly

- Pick a hard niche (e.g. browser protocols, SAP, mobile RE)  
- Teach (blog, talk, mentoring) — teaching reveals gaps  

## FR

Hebdo : profondeur + écriture. Mensuel : cimetière + checklists. Annuel : niche + transmission.
