# Edge, DNS & Takeover Classes

## Subdomain takeover class

When a DNS record points to an unclaimed third-party resource (deprecated SaaS).

### Discipline

- Confirm **dangling** state carefully  
- Prefer proof via provider’s standard claim flow on a resource **you control**  
- Do not hijack to phish real users  
- Some programs have special takeover rules  

## CDN / cache

- Cache key issues leading to content mix-up between users (advanced)  
- Poisoning claims need strong, non-destructive evidence  

## FR

Takeover : prouver dangling sans phishing. Cache poisoning : preuves solides et non destructives.
