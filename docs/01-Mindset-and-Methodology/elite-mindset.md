# Elite Hunter Mindset / Mentalité du hunter d’élite

<!-- updated: 2026-03 -->

## English

### Core beliefs

1. **Bugs are mismatches** between intended trust model and implemented reality  
2. **Noise is the enemy** — every request should test a hypothesis or map a node  
3. **Programs pay for risk reduction**, not for cleverness theater  
4. **Your reputation compounds** — clean reports unlock private invites  
5. **Depth beats spray** on mature targets; spray only after high-signal filters  

### Anti-patterns of stuck hunters

| Anti-pattern | Replace with |
|--------------|--------------|
| Tool-first every morning | Feature-first read of one flow |
| Severity inflation | Honest impact + program language |
| Infinite recon without tests | Time-box recon → force hypotheses |
| Rage-quitting after N/A | Postmortem: was scope, quality, or luck? |
| Secret-keeping from your notes | Write assumptions; kill them later |

### Emotional regulation (underrated OPSEC)

- Fatigue causes scope mistakes and noisy traffic  
- FOMO on leaderboards destroys deep work  
- Celebrate **process adherence**, not only payouts  

### Pro tip

Top hunters keep a private “**graveyard**” of dead hypotheses. It prevents re-testing the same wrong idea and trains pattern recognition.

## Français

### Croyances centrales

Les bugs sont des **écarts de modèle de confiance**. Le bruit est l’ennemi. Les programmes paient la **réduction de risque**. La réputation se capitalise. La profondeur bat le spray sur cibles matures.

### Anti-patterns

Outils d’abord → features d’abord. Inflation de sévérité → impact honnête. Recon infini → time-box + hypothèses. Abandon émotionnel → postmortem. Notes pauvres → écrire les hypothèses.
