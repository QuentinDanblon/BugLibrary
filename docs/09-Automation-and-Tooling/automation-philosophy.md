# Automation Philosophy

## English

Automate **boring, high-precision** work. Never automate recklessness.

| Automate | Keep human |
|----------|------------|
| Scope parsing reminders | Severity judgment |
| Delta recon alerts | AuthZ creative tests |
| Dedup endpoints | Chain impact narrative |
| Evidence packaging | Platform submission |
| Dead hypothesis archival | Legal grey calls |

### Quality bar for a bot

A bot is “good” if it **reduces human search space** without increasing legal risk.

## FR

Automatiser l’ennuyeux et le précis. Le jugement, le légal et la soumission restent humains.
