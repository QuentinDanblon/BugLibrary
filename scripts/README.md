# Scripts

Utility scripts for **documentation hygiene** and safe local helpers.  
No exploit payloads.

| Script | Purpose |
|--------|---------|
| `check_structure.py` | Verify required BugLibrary layout |
| `new_hypothesis.md` | (see templates) use templates instead for content |

## Running structure check

```bash
python scripts/check_structure.py
```

Exit code `0` = layout OK.
