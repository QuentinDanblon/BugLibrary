# assets/

Dossier réservé aux diagrammes, images, et ressources visuelles complémentaires à la documentation (les diagrammes de flux principaux sont directement en Mermaid inline dans les fichiers Markdown pour rester versionnables en texte).

Ajouter ici toute image (capture d'écran anonymisée d'exemple, schéma d'architecture d'attaque) référencée par un document de `docs/`. Nommer les fichiers de façon descriptive et les référencer par chemin relatif depuis le document concerné.
